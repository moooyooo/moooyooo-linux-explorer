# ショートカットと操作対象

Windows Explorerの一般的な割り当てを基本とします。MDIとプロジェクト固有の差分を明示します。特に **Ctrl+Nは利用者指定により、親ではなく現在のMDI内に子を追加** します。Linuxデスクトップが先に取得するグローバルキーは奪いません。[Microsoftの公式一覧](https://support.microsoft.com/en-us/windows/keyboard-shortcuts-in-windows-dcc61a57-8ff0-cffe-9796-cb9706c75eec)

## 親・子・プロジェクト

| キー | コマンドID | 動作 | 区分 |
|---|---|---|---|
| Ctrl+N / Ctrl+T | pane.new | 現在の位置を新しい子で開く。子がなければホーム | MDI向けの指定 / タブ操作の別名 |
| Ctrl+W / Ctrl+F4 | pane.close | アクティブな子を閉じる。最後の子でも親は残る | MDI向けの差分 |
| Ctrl+Tab / Ctrl+F6 | pane.next | 次の子。表示順を循環 | MDI |
| Ctrl+Shift+Tab / Ctrl+Shift+F6 | pane.previous | 前の子 | MDI |
| Ctrl+Alt+N | workspace.new | 未保存の新しい親を別プロセスで開く | アプリ固有 |
| Alt+F4 | workspace.close | 現在の親を終了。dirtyと実行中ジョブを確認 | OS標準 |
| Ctrl+O | project.open | プロジェクトを選び、新しい親で開く | アプリ固有 |
| Ctrl+S | project.save | 現在の親のプロジェクトを保存 | アプリ固有 |
| Ctrl+Shift+S | project.save_as | 新しいIDのプロジェクトとして保存先を選ぶ | アプリ固有 |
| F11 | workspace.fullscreen | 親の全画面表示を切り替える | Explorer系 |

整列・MDI／タブ切り替えには初期のショートカットを割り当てず、「ウィンドウ」メニューから実行します。子を閉じてもその子が開始したジョブを暗黙に中断せず、親のジョブパネルで追跡します。

## 移動・表示

| キー | 動作 | 対象 |
|---|---|---|
| Alt+Left / Backspace | 戻る | 子。Backspaceは入力欄では文字削除 |
| Alt+Right | 進む | 子 |
| Alt+Up | 上のフォルダ | 子。表示上のパスの親へ移動 |
| Alt+D / Ctrl+L | アドレス全選択 | 子 |
| F4 | アドレス入力と現在セッションの候補を開く | 子 |
| Ctrl+E / Ctrl+F / F3 | 現在フォルダの名前検索へ移動 | 子 |
| F5 / Ctrl+R | 再読み込み。選択を可能な限り維持 | 子 |
| Alt+P | 限定プレビューパネルの表示切り替え | 子 |
| Alt+Enter | プロパティ。ディレクトリ容量は明示要求で非同期計算 | 一覧・ツリー |
| Ctrl+Shift+E | ツリーで現在の場所までの祖先を展開して選択 | 子 |
| Ctrl+H | 隠しファイルの表示切り替え | Linuxでの追加 |
| Ctrl+ホイール | アイコンサイズの変更 | アイコン表示時 |
| F6 / Shift+F6 | ツリー→一覧→アドレス→検索→表示中プレビューを巡回 | 子 |
| Tab / Shift+Tab | 標準のフォーカス移動 | 画面全体 |
| Escape | 入力キャンセル／検索解除／メニューを閉じる | 最も内側の対象 |

## 一覧とファイル操作

| キー | 動作 |
|---|---|
| 矢印、Home、End、PageUp、PageDown | 一覧の位置移動。Shift併用で範囲選択 |
| Ctrl+矢印、Ctrl+Space | 選択を保持した位置移動と個別選択の切り替え |
| Ctrl+A | フォーカスのある一覧の全項目を選択 |
| Enter | フォルダは同じ子で開く。通常ファイルは既定アプリで開く |
| F2 | 単一選択の名前変更。複数選択時の一括リネームは初版対象外 |
| Ctrl+Shift+N | 新しいフォルダ。名前入力後に実行 |
| Ctrl+C / Ctrl+X / Ctrl+V | コピー／切り取り予約／貼り付け |
| Delete | ごみ箱に移動。ごみ箱を利用できなければ失敗を説明 |
| Shift+Delete | 完全削除。件数・対象を確認してから実行 |
| Ctrl+Z / Ctrl+Y | 対応するファイル操作のUndo / Redo。制限は操作仕様に従う |
| Shift+F10 / Menuキー | 選択項目のコンテキストメニュー |
| 文字入力 | 一覧で先頭一致の名前へ移動。IME確定文字を受け付ける |

ツリーではRightで展開、Leftで折りたたみ／親へ、テンキー＋／−で展開／折りたたみとします。テンキー＊による全階層展開は巨大ツリー走査を防ぐため初版では割り当てません。Win+E等のデスクトップ起動キーもアプリでは登録しません。

## フォーカスと競合の規則

1. モーダルダイアログ、メニュー、IMEが操作を優先する。変換中のキーでファイル更新・子追加を発火させない。
2. アドレス・検索・名前変更等の入力欄ではCtrl+A/C/X/V/Z/Y、Delete、Backspace、Home/End、矢印をテキスト編集に渡す。Undoでファイルを動かさない。
3. 更新系コマンドはフォーカスのあるファイル一覧・ツリーから明示的な選択と移動先を得られる場合だけ有効にする。
4. 共通ツールバーをクリックしても直前のアクティブな子を対象にする。子がない場合は子固有コマンドを無効にする。
5. 別の親の履歴・選択・Undoは使用しない。OSクリップボードによる親間転送だけを共有の入口とする。
6. キー定義、表示名、対象スコープ、enabled条件はCommandRegistryへ集約する。キーのカスタマイズ画面は後続工程とする。
