# [EXP-005] ライセンスと配布パッケージ

<!-- mlex-backlog:EXP-005 -->

優先度: P1。ソースのPublic公開は利用者が指定済みです。プロジェクトのライセンス選択とバイナリ配布は未完了です。

- [ ] 所有者がプロジェクトのライセンスを選び、LICENSEを追加する。
- [ ] 配布するQt / GIO等の実バージョン、ライセンス、著作権表示、配布条件を確認する。
- [ ] 本体と操作ワーカーを同じbinに配置するパッケージを作る。
- [ ] desktopエントリーとプロジェクト形式の関連付けを用意する。
- [ ] クリーン環境で導入・起動・削除を確認し、確認済みの成果物だけをリリースする。

ソース公開とバイナリ配布を別の達成状況として記録します。ライセンスを勝手に決定したり、未検証の配布物を完成扱いにしたりしません。
