# [EXP-002] ファイル操作の障害・競合検証

<!-- mlex-backlog:EXP-002 -->

優先度: P1。主要操作・中断・Undoの自動テストに加え、媒体と並行更新に伴う失敗を検証します。

- [ ] 異なるファイルシステムへの移動と、途中失敗時に残る元・先を検証する。
- [ ] 容量不足、権限不足、媒体切断、ワーカー異常終了を検証する。
- [ ] 外部プロセスによる親フォルダ・リンク・対象の差し替えを検証し、残る競合条件を整理する。
- [ ] 不確かな結果を成功と表示せず、ごみ箱失敗が完全削除に切り替わらないことを確認する。
- [ ] ACL、拡張属性、ハードリンク、非UTF-8名の制限を利用者に分かる形で表示する。

破壊的な失敗の再現は、実データを置かない一時領域・テスト用媒体だけで行います。
