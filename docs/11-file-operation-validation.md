# 主要ファイル操作の実装と検証

2026-10-09、バージョン0.2.0。内部ファイラのステータス、ホームを開く初期値、操作名の統一とWindows系の主要ショートカットを追加しました。

## 実装した範囲

- 内部ファイラごとの表示件数、一覧の選択件数、選択ファイルのサイズ、進捗・結果。検索や選択の変化に追従し、フォルダ容量を再帰走査しません。
- Ctrl+N / Ctrl+Tと「内部ファイラを追加」はホームを開きます。閉じる・切り替え等も同じ呼び方に統一しました。保存した場所やCLI指定は保持します。
- F2はファイル・フォルダの単一名前変更。ファイルは拡張子を除いた部分を選択します。Ctrl+Shift+Nは実フォルダの作成です。
- Ctrl+C / X / V、Delete、Shift+Delete、Ctrl+Z / Y。編集メニューと右クリック・Shift+F10 / Menuからも実行できます。文字入力欄とIME変換中はファイル操作を発火しません。
- Qt Core + GIOの操作ワーカー。更新処理は別プロセス、親ごとに1件、64KiB単位のコピー。進捗・中断・部分成功を返し、ごみ箱失敗を完全削除へ変更しません。
- 同名のスキップ・別名保持、排他的な確定、リンク自身の操作、対象の同一性検証、条件付きの20件Undo / Redo。変更されたコピー先・フォルダを取り消しで消しません。
- ソース・サンプルに実パスやファイル内容を埋め込まず、実行時記録はXDG状態領域に0700 / 0600で保存。ワーカーへ実パスをコマンドラインで渡しません。

## 自動検証

`cmake --preset dev`、`cmake --build --preset dev --parallel 4`、`ctest --preset dev` で再現できます。`operations` を加えた6グループで次を確認します。

- 既存のプロジェクト保存・競合・復元・CLI・独立プロセス。
- 内部ファイラの独立した状態表示、検索時の件数、ホーム追加、入力欄のDelete・Ctrl+C・Ctrl+Z、IME中のF2・削除抑止。
- GUIからキー入力で名前変更、フォルダ作成、子間のコピー・切り取り・貼り付け、Undo / Redo、ごみ箱、完全削除の確認キャンセル。
- ツリーで選択した宛先へのフォルダ作成、名前変更時に開いている子の追従、空白の右クリックで選択解除、ジョブ完了を待ってからの終了。
- ワーカーによるファイル・フォルダ操作。同名を上書きしないこと、選択後の差し替え、子孫へのコピー、親子を重ねた選択、特殊ファイル、循環・破損リンク、途中中断と一時領域の片付け。
- 操作後の編集・内容追加を検出する取り消し、多項目の事前確認、連続操作のUndo / Redo、やり直しを繰り返した際の履歴。
- 実ワーカーのIPC、起動失敗・不正プロトコル、キャンセル、ごみ箱、非Undo操作による履歴の破棄、操作記録と権限。
- GNOME / KDE形式とローカルURI、未知の形式・リモートURIの拒否、アプリ内の切り取り時点の識別情報保持。

テストはリポジトリ外の架空データだけを使用します。HOME / XDG_DATA_HOME / XDG_STATE_HOMEを隔離し、実際のホーム一覧や利用中のごみ箱を使いません。offscreenにはウィンドウマネージャーがないため、ダイアログ後の親の再アクティブ化をテスト側で行います。

ステータスバーのサイズ表示は利用者のロケールに従います。公開前確認で日本語環境におけるテストの英語単位固定を修正し、選択ファイルの実サイズとロケールに応じた表示を照合するようにしました。同じ操作を日本語・英語の両ロケールで検証します。

ASan / UBSanは[前版と同じコマンド](10-implementation-validation.md#検証の再現)で実行します。環境のptrace制限によりLeakSanitizerは無効とし、リーク検査を実施済みとは扱いません。Pythonの仕様・公開前検査も併用します。

通常版・ASan / UBSan版ともCTestの6グループが成功しました。仕様チェック、Pythonの15テスト、個人情報・秘密情報の作業ツリー検査も成功しています。画面は架空データのoffscreen画像で確認し、画像をリポジトリに保存していません。

## 制限と残る実機確認

ドラッグ転送、プレビュー、置換・フォルダ統合、再起動後のUndo、詳細なジョブ履歴画面は未実装です。コピーのACL・拡張属性・ハードリンク構造は完全保持を保証しません。取り消し記録・操作件数・メッセージには[仕様の上限](06-file-operations.md)があります。

ごみ箱・完全削除・異なるFS移動・部分成功は取り消し対象外です。外部変更や差し替えで履歴の前提が崩れた場合も操作を止めます。中断で完了した項目を自動で巻き戻しません。異常終了や強制終了は未完了記録を残し、再実行せず実ファイルを確認する扱いです。

Wayland / X11、GNOME / KDEの実クリップボード、ごみ箱のデスクトップ表示、実IME、異なるFS間の移動、容量不足・媒体切断・中断不能I/O・電源断、10万件時の性能は未検証です。コピー・削除時の同一性を検査していますが、非協調の外部プロセスとの全ツリーの原子的な排他は保証しません。

起動は通常のターミナルで `sh tools/run.sh`、架空データの確認は `python3 tools/demo.py` です。エージェント環境からのデスクトップ接続制限は前版と同じです。
